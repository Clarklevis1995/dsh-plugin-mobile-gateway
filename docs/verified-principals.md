# Actor-bound Whaleness gateway

Configure `platformAuth: true` and mount after `platformAccess` and `platformExecution`. Startup fails if platform access is unavailable. There is no owner Peer in platform mode. Each WebSocket verifies trusted Tailscale Serve identity through existing `platformAccess.authenticateHttp`, checks its separately paired device and immutable device/principal binding, then uses an actor Peer from existing `acquirePrincipalPeer`.

All native calls, session followers, workspace/control streams, uploads, voice and plugin operations use that actor API. Native RemoteAccess remains authoritative; settings and plugin administration do not gain owner rights. Session creation goes through `createSessionForPrincipal` with one validated project/workspace binding. Question/approval replay and answers require current `canAnswer`; global Host event projections are filtered for each recipient. Identity expiration/revocation closes the socket and its streams. Both mobile channels use the same principal; no user-supplied identity is accepted.

File browsing and chunked downloads use the session's actual execution-realm filesystem and verify containment/current read access at each response. Attachment ingress is written through existing `platformExecution.writeArtifact` before official attachment admission. No arbitrary Host file path is exposed. Existing upload spool and device credential stores remain private control-plane operational state.

The management panel reuses the upstream English/Japanese locale implementation from commit `2cfe44c3151d4c30536287d35d0960b71841be9b` (present in upstream main, absent from the published npm baseline). The small locale selection change respects Host document language, preserves Chinese/Japanese, and defaults other locales to English. No automatic public tunnel, VPN, Tailscale profile/share, router or firewall configuration is performed. Use the deployment's existing Tailscale Serve routing for `/ws/mobile`; do not point Whaleness at a Pocket PIN endpoint or hand out a loopback pairing URL.

Native iPhone client: [Whaleness TestFlight](https://testflight.apple.com/join/1Euwby6r), compatible protocol 3. Physical installation/pairing and a reachable authorized Serve endpoint remain activation actions. Local source checks are syntax only; runtime/isolated release assembly belongs to the GitHub build.
